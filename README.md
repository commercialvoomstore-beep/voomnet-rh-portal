# 🏢 Portail RH, Paie & Communication Internes - VOOMNET TECHNOLOGY

Application Web moderne et réactive développée avec **Next.js 14**, **React 18**, **TypeScript** et **Tailwind CSS** pour la gestion intégrée des Ressources Humaines, de la Paie et des Communications d'entreprise chez **VOOMNET TECHNOLOGY** (Abidjan, Côte d'Ivoire).

---

## 🚀 Fonctionnalités Principales

### 1. 📊 Tableau de Bord RH & Cockpit Direction
- Statistiques de masse salariale et effectifs en temps réel.
- Suivi des départements (Direction, Support Télécom, Réseaux 3CX, Développement Logiciel).
- Graphiques d'assiduité et d'activité des postes.

### 2. 👥 Gestion du Personnel & Fiches Salariés
- Annuaire complet avec matricule 3CX, coordonnées, statut et contrats.
- Consultation et mise à jour des informations d'embauche.

### 3. 💵 Module de Paie, Primes & Bulletin de Salaire
- Moteur de calcul automatisé des bulletins de salaire.
- Prise en compte des primes de rendement, indemnités de transport et retenues.

### 4. 💬 Module Chat RH & Messagerie Interne
- **Communication Humaine Directe** : Messagerie directe expéditeur-destinataire.
- **Indicateurs de Remise & Statut** : Badges et coches de confirmation de livraison (`✓ Envoyé`, `✓✓ Envoyé & Distribué au Poste X`).

### 5. 🌴 Gestion des Congés & Absences
- Soumission et validation des demandes de congés annuels, permissions et motifs de santé.

---

## 🛠️ Stack Technique & Installation

- **Framework** : Next.js 14.2 (App Router)
- **Langage** : TypeScript
- **Styles** : Tailwind CSS
- **Icônes** : Lucide React

```bash
# Installation des dépendances
npm install

# Lancement en mode développement (Port 3000)
npm run dev

# Build de production
npm run build
npm start
```
